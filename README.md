# Αλατιέρα Static Template

Static HTML, CSS and JavaScript rebuild for the Αλατιέρα website.

The template now includes restaurant presentation sections plus expanded content modules for:

- athlete profiles
- records and performance boards
- blog/editorial posts
- image galleries
- video highlight cards
- filterable media hub
- archive pages and single detail pages for posts, athletes, records, galleries, videos, and images

## Files

- `index.html` contains the full page markup.
- `blog/` contains the blog archive and single post templates.
- `athletes/` contains athlete archive and profile templates.
- `records/` contains the records archive.
- `media/` contains media archive, video pages, and image pages.
- `galleries/` contains gallery album pages.
- `assets/css/site.css` contains the responsive visual system.
- `assets/js/main.js` contains the small interactive behaviors.
- `assets/img/` contains the reused image assets.

## Run

Open `index.html` directly in a browser, or serve the folder from XAMPP:

```text
http://localhost/alatiera/
```

No PHP, database, admin panel or server-side runtime is required.
